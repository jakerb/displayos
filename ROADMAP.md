# POC roadmap

Open defects and their acceptance criteria are tracked in
[`KNOWN_ISSUES.md`](KNOWN_ISSUES.md).

- [x] Milestone 0: monorepo bootstrap and macOS application build.
- [x] Milestone 1 (foundation): mDNS receiver advertisement and host discovery UI.
- [ ] Milestone 2: ScreenCaptureKit capture, VideoToolbox H.264 encode, receiver decode/render.
- [ ] Milestone 3: direct-link addressing, transport metrics, latency tuning.
- [ ] Milestone 4: authenticated pairing and encrypted sessions.
- [ ] Milestone 5: signed receiver application updates and host proxy transfer.
- [x] Milestone 6 (boot foundation): reproducible Intel Debian live ISO, service autostart, no login UI.
- [ ] Milestone 7: Wi-Fi provisioning and persistent configuration partition.
- [ ] Milestone 8: isolated macOS virtual-display experiment.
